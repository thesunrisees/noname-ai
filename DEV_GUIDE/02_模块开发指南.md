# 模块开发指南

---

## 如何新建一个模块

### 1. 基本模板

```javascript
/* ================= 模块名 =================
 * 描述：模块功能说明
 * 作者：飞升
 * 版本：1.0.0
 */

/* 模块内部状态 */
const _state = {};

/* 对外接口 */
export function moduleFunction(me, ctx) {
    try {
        // 你的逻辑
        return result;
    } catch (e) {
        return defaultValue;
    }
}

/* 重置状态 */
export function resetModule() {
    // 清空状态
}
```

---

### 2. 集成到 engine.js

#### 步骤 1：import

在 `engine.js` 顶部 import 区加：

```javascript
import { moduleFunction, resetModule } from './yourModule.js';
```

#### 步骤 2：在 bestAction 里调用

找到 `bestAction` 函数里的评分循环，加：

```javascript
try {
    const bonus = moduleFunction(me, ctx);
    s += bonus;
} catch (e) {}
```

#### 步骤 3：在 clearScoreState 里重置

找到 `clearScoreState` 函数，加：

```javascript
try { resetModule(); } catch (e) {}
```

## 模块分类

### 1. 评分模块（最常见）

**职责**：给动作打分，加分或减分

**示例**：

```javascript
/* ================= 风险量化 ================= */
export function riskScore(me, target) {
    let score = 0;
    
    // 残血目标加分
    if (target.hp <= 1) score += 2;
    
    // 有闪目标减分
    if (probHasShan(me, target)) score -= 1;
    
    return score;
}
```

**集成**：

```javascript
// engine.js
try {
    s += riskScore(me, target);
} catch (e) {}
```

---

### 2. 预测模块

**职责**：预测对手行为或牌堆

**示例**：

```javascript
/* ================= 对手手牌推断 ================= */
export function inferHand(player) {
    return {
        sha: 0.5,    // 有杀的概率
        shan: 0.4,   // 有闪的概率
        tao: 0.1,    // 有桃的概率
    };
}
```

**集成**：

```javascript
// engine.js
const hand = inferHand(target);
if (hand.shan > 0.5) s *= 0.8;  // 对手有闪，减分
```

---

### 3. 策略模块

**职责**：提供策略建议

**示例**：

```javascript
/* ================= 局势评估 ================= */
export function evaluateSituation(me) {
    return {
        label: '优势',   // 局面标签
        score: 0.7,     // 局面评分
        color: 'green', // 颜色
    };
}
```

**集成**：

```javascript
// engine.js
const sit = evaluateSituation(me);
s *= (0.8 + sit.score * 0.4);  // 局面越好，分越高
```

---

### 4. 数据模块

**职责**：管理数据（记忆、缓存等）

**示例**：

```javascript
/* ================= 牌堆记忆 ================= */
const _deck = {};

export function deckConsume(card) {
    // 记录牌已出现
}

export function cardRemaining(name) {
    // 查询剩余数量
}
```

## 开发规范

### 1. 错误处理

所有对外接口必须有 try-catch：

```javascript
export function yourFunction(me) {
    try {
        // 你的逻辑
        return result;
    } catch (e) {
        return defaultValue;  // 出错时返回默认值
    }
}
```

---

### 2. 性能优化

1. **避免重复计算**：用缓存
2. **零对象分配**：复用对象
3. **延迟计算**：1 秒缓存
4. **异步执行**：用 setTimeout

```javascript
let _cache = null;
let _cacheTs = 0;

export function yourFunction() {
    const now = Date.now();
    if (_cache && (now - _cacheTs) < 1000) return _cache;
    
    _cache = compute();
    _cacheTs = now;
    return _cache;
}
```

---

### 3. 命名规范

- 文件名：小写 + 驼峰（如 `riskQuant.js`）
- 函数名：小写 + 驼峰（如 `riskScore()`）
- 常量：大写 + 下划线（如 `MAX_SAMPLES`）

---

### 4. 注释规范

```javascript
/* ================= 模块名 =================
 * 描述：模块功能说明
 * 作者：飞升
 * 版本：1.0.0
 *
 * 接口列表：
 *   - function1(me, ctx)：描述
 *   - function2(me, ctx)：描述
 */
```

## 测试

### 1. 控制台测试

```javascript
// 测试模块
import('./score/yourModule.js').then(m => {
    console.log(m.yourFunction(me, ctx));
});
```

### 2. 打游戏测试

1. 打几局游戏
2. 观察 AI 行为是否符合预期
3. 打开控制台查看日志

### 3. 性能测试

```javascript
// 计时
const t0 = performance.now();
yourFunction(me, ctx);
const t1 = performance.now();
console.log('耗时：', t1 - t0, 'ms');
```

## 常见错误

### 1. import 路径错误

```
错误：Cannot find module './yourModule.js'
解决：检查文件路径是否正确
```

---

### 2. 未定义变量

```
错误：ReferenceError: me is not defined
解决：检查变量是否定义
```

---

### 3. 性能问题

```
现象：游戏卡顿
解决：
1. 加缓存
2. 减少计算量
3. 用异步执行
```

## 发布

### 1. 增量更新

只打包修改了的文件：

```bash
zip yourModule.zip score/yourModule.js score/engine.js
```

### 2. 版本号

- 不要用 1.2 以后的版本号
- 用 1.0.x 系列（如 1.0.1, 1.0.2）
- 每次更新必须新增对应版本号更新日志文件

### 3. 更新日志

在 `changelog.js` 里加：

```javascript
{
    version: '1.0.x',
    name: '模块名',
    desc: '模块描述',
    date: '2024-01-01',
},
```
