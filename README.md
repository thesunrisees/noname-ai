## 🎮 这是什么？

**无名AI** 是一款基于**决策积分引擎**的三国杀 AI 扩展，它不是简单的规则引擎，而是一个**会自己学习、自己进化**的智能体。

它能：
- ✅ **自己学习**：打得多了，自动知道哪些技能/卡牌好用
- ✅ **自己校准**：打错了，自动调整策略，越打越准
- ✅ **自己进化**：用遗传算法，自动优化出牌策略
- ✅ **可观测**：每一步决策都能回放，知道 AI 为什么这么选

---

## ✨ 核心功能

### 🧠 自我学习系统
- **元素反馈**：打得多了，自动记录每个技能/卡牌的实际效果
- **跨模式迁移**：身份局学的"杀很有用"，国战/斗地主也能用
- **元认知**：AI 知道自己"熟不熟"——熟悉的局面敢用模型，陌生的局面保守出牌

### ⚖️ 自我校准系统
- **自动校准**：每局结束，自动对比"规则说的"和"实际结果"，微调策略
- **权重持久化**：校准结果直接刻进模型权重，下次开局就生效
- **模型热更新**：攒够样本自动训练，跑 A/B 测试，胜率高才替换旧模型

### 🧬 自我进化系统
- **多档案协同**：5 种性格档案（激进/保守/均衡/守护/独狼），互相学习
- **策略进化**：遗传算法：精英保留 + 杂交 + 变异，自动进化出最优策略
- **公共知识库**：所有 AI 共享"局面→正确选择"的群体智慧

### 🛡️ 安全护栏
- **模型护栏**：8 条红线拦截，防止 AI 做出离谱操作（打队友、自残等）
- **策略总线**：规则和模型冲突时，自动用 2 步深度规划做最终裁决

### 📊 可视化面板
| 面板 | 说明 |
|---|---|
| 🧠 AI 大脑总览 | 一屏看完所有模块状态 |
| 📈 校准趋势 | 看校准偏移怎么变化，胜率趋势 |
| 🎬 决策回放 | 每一步决策完整链路：状态→候选→模型→执行→结果 |
| ⚖️ 决策对比 | 同一局面，不同性格档案会怎么选？ |
| 🔍 模块自检 | 一键检查所有模块是否正常工作 |

## 🚀 快速开始

### 安装
1. 下载最新 [Release](https://github.com/your-repo/noname-ai/releases)
2. 解压到无名杀扩展目录
3. 重载扩展即可

### 验证
打开控制台（F12），跑：
```javascript
window.__DJSC.openSelfCheck();
```
应该全绿。

### 开始使用
1. 打几局，让 AI 开始学习
2. 打开「🧠 AI 大脑总览」看学习效果
3. 打得多了，AI 会越来越强

## 📊 技术亮点

| 项 | 说明 |
|---|---|
| 特征维度 | 96 维 Int8 量化 |
| 网络结构 | 96 → 64(ReLU) → 6 多层网络 |
| 元认知 | 6 维架构（元素/模式/局面/目标/局势/时间） |
| 校准器 | 单次调整 ≤ 0.03，累计偏差 ≤ 0.3 |
| 进化算法 | 种群 8，精英保留 Top 2，变异率 15% |
| 热更新 | 攒 300 样本自动训练，跑 20 局 A/B 测试 |

## 📁 目录结构

```
无名AI/
├── extension.js          # 扩展入口
├── info.json             # 扩展信息
├── assets/               # 静态资源
├── css/                  # 样式
├── js/                   # 配置面板
│   └── config.js         # 所有面板入口按钮
└── score/                # 决策积分引擎（核心）
    ├── engine.js         # 核心引擎
    ├── features.js       # 96维特征提取
    ├── weights.js        # 多层神经网络
    ├── metaCognition.js  # 6维元认知
    ├── decisionCalibrator.js  # 自动校准
    ├── multiProfile.js   # 多档案协同
    ├── strategyBus.js    # 策略总线
    ├── modelGuard.js    # 模型护栏
    ├── weightPersist.js # 权重持久化
    ├── crossModeTransfer.js  # 跨模式迁移
    ├── evolution.js     # 策略进化（遗传算法）
    ├── modelHotSwap.js  # 模型热更新
    ├── sharedKnowledge.js   # 公共知识库
    ├── brainDashboard.js    # AI大脑总览面板
    ├── decisionReplay.js    # 决策回放记录
    ├── replayPanel.js       # 决策回放面板
    └── ...                 # 更多模块
```
