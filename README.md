# 无名AI · 决策积分引擎

> 无名杀扩展 - AI 决策积分引擎 v1.0.0

---

## 项目简介

**无名AI** 是一个三国杀（无名杀）纯策略决策扩展，为 AI 提供更智能的出牌决策能力。

核心思路：AI 每次出牌时枚举所有候选动作，通过多层信号加权打分，选最高分动作执行。

---

## 核心功能

### 🧠 决策积分引擎
- **bestAction**：枚举所有候选动作，多层信号加权打分，选最高分执行
- **记分系统**：实时记分，玩家得分累积，阵营分按均摊守恒
- **效果处理**：damage/recover/draw/discard/gain/lose/judge 全覆盖

### 🎯 技能识别系统
- **对象-方法交叉扫描**：通过"对谁做"判断技能正负号，比关键词识别更精确
- **八维度评分**：对象/范围/时机/频率/风险/持续，输出 -15 ~ +15 综合分
- **子技能继承**：子技能从主技能继承标签（×0.5），覆盖率 95%+

### 🃏 牌堆记忆引擎
- **多模式适配**：7 种模式（身份/国战/斗地主/BOSS/对战/单挑/默认）
- **牌堆预测**：判定成功率 + 牌名稀缺度 + 摸牌期望
- **UI 同步**：从 ui.cardPile.children 重建（以真实 DOM 为准）

### 🛡️ 威胁评估系统
- **敌方威胁评估**：手牌/装备/技能/血量
- **命中率计算**：敌方有闪概率 / 有八卦概率
- **座位压力**：座位距离压力评估

### 👥 阵营关系精细化
- **11 种模式精细阵营判断**
- **友方延迟评估**：600ms 延迟评估，50%/70% 惩罚
- **锦囊友方惩罚**：乐/兵/铁索横置重罚，解除横置加分
- **顺手牵羊友方判断**：拿判定区加分，拿非判定区重罚

### 📊 训练蒸馏系统
- **48 维特征提取**：32 状态 + 16 动作
- **样本缓冲**：缓冲每局训练样本，游戏结束后导出 JSON
- **Python 蒸馏**：Ridge 回归训练，生成权重文件

---

## 安装方法

1. 下载最新版本的 zip 文件
2. 解压到无名杀的 `extension/` 目录
3. 重启无名杀，在扩展管理里启用「无名AI」

---

## 使用说明

### 配置面板
- 打开「菜单 → 选项 → 其它 → 无名AI」
- 调整各种参数（性格/风险/团队等）

### 决策面板
- 游戏中按快捷键打开决策面板
- 查看 AI 每个决策的候选动作和分数

### 训练数据导出
- 打 10 局以上
- 在配置面板点「导出训练数据」
- 用 Python 脚本蒸馏权重
